### 🛡️ Compact DDoS Stress Test Script

This is a lightweight and compact DDoS stress test script written in C++. It is designed for educational and network testing purposes only.

#### 🚀 Features
- **Easy to Use**: Simply enter the target IP address and port to launch the test.
- **Real-time Monitoring**: The program displays the attack speed and traffic in real-time.
- **Multi-threaded**: Utilizes multiple threads for higher performance and impact.
- **Cross-Platform**: Compatible with any device capable of compiling C++ programs, including PCs, Android devices (via Termux), and Raspberry Pi.
